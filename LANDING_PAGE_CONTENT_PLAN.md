# Kontentino GPT Apps - Landing Page Content Plan

## 📋 Executive Summary

**Purpose**: Transform the generic waitlist template into a compelling landing page for Kontentino GPT Apps - a revolutionary integration bringing social media content approvals directly into ChatGPT.

**Target Audience**: Social media managers, content creators, marketing teams who use ChatGPT for content creation

**Key Message**: Create with AI in ChatGPT, visualize and approve with Kontentino - seamlessly.

**Tone**: Innovative, exciting, professional, early-access exclusive

## 🎬 Video/Screenshot Specifications

### What to Show:

**Option 1: Video (15-30 seconds)**
1. User asks ChatGPT: "Create a Instagram post about summer sale"
2. ChatGPT generates text
3. User says: "Show me a preview"
4. Kontentino widget appears with Instagram preview
5. User exports as PDF
6. Cut to: Email with PDF attachment arriving

**Option 2: Screenshot/GIF**
- Split screen showing:
  - Left: ChatGPT conversation
  - Right: Kontentino preview widget
- Annotations pointing to key features

**Option 3: Carousel (3-5 images)**
1. ChatGPT generating content
2. Kontentino showing preview
3. Export options (PDF/Image/Email)
4. Calendar view
5. Post List view

### Technical Specs:
- **Format**: MP4 (video) or WebP/PNG (images)
- **Aspect Ratio**: 16:9 or 3:2
- **Max Size**: 5MB for images, 10MB for video
- **Dimensions**: 1200x800px minimum
- **Quality**: High-res, shows UI clearly
- **Text**: Minimal on-screen text, let visuals speak

**Recommended**: Option 1 (short video) - most engaging, shows workflow

## 🎯 Key Messaging Principles

Throughout all copy:

1. **AI + Kontentino Partnership**: Always emphasize the seamless integration
2. **Approvals Differentiator**: Highlight this unique value prop
3. **Professional Tone**: B2B, not consumer
4. **Benefit > Feature**: Focus on what users gain, not just what it does
5. **Urgency**: Early access, limited spots, be first
6. **Clarity**: Simple language, no jargon
7. **Visual**: Use emojis sparingly but effectively
8. **Action-Oriented**: Every section should push toward signup
